# gnox-marketplace

`gnox-marketplace` provides the operational core and environmental instrumentation required to build agents with verifiable structural integrity. This repository hosts the `gnox` suite—a collection of deterministic, engineering-focused tools designed for `claude-cli`. These mechanisms establish a foundation of audit-grade transparency through formal compliance modeling, provable artifact lifecycle management, and tamper-evident storage layers built on invariant engineering principles.

## Suite Overview

The `gnox` suite operates as a unified governance and instrumentation system. It combines `gnox-risk-management`, which defines the compliance and policy framework, with `stalker`, which enforces that framework through immutable physical and environmental records. Together, they form a complete, verifiable operational loop: policy defines the objective, and instrumentation ensures the execution remains within boundary-defined integrity.

### Governance Plugin: `gnox-risk-management`
This plugin establishes a formal compliance and risk-modeling framework for AI-assisted systems. It shifts the burden of documentation from static templates to an automated, auditable methodology.
*   **`gnox-rm-bootstrap`**: The centralized engine for managing controlled documentation programs. It applies invariant engineering rules to ensure all artifacts (e.g., system characterizations, control architectures, risk-scenario assessments) are developed, verified, and matured through a formal registry of accountability, grounded in pinned regulatory reference corpora rather than model memory.

### Enforcement Plugin: `stalker`
This plugin provides the environmental instrumentation for vigil-based security and provable artifact disposition. It ensures that the operational integrity defined by `gnox-risk-management` is maintained through physics and protocol, making falsification unconstructable.
*   **`reliquary`**: The substrate for tamper-evident storage. It constructs a file-backed ZFS environment where contracts, affirmation chains, and signed append-only ledgers are sealed on read-only media, ensuring that the integrity of the agent's foundation is verifiable by strangers forever.
*   **`mount-doom`**: The ceremony protocol for artifact unmaking. It ensures that any destructive action (revoking credentials, decommissioning compromised images) is recorded in the immutable reliquary ledger with the same rigor as creation, rendering "vanishing" impossible.
*   **`stalker`**: The session watcher (stalcaire). It ensures deterministic provenance verification at agent arrival, challenging new instances against the established reliquary ledger to ensure an authenticated, verified biography before work commences.
